# What the pipeline itself needs. Kept minimal so a fresh clone -- or a CI job
# that only rebuilds the bibliography -- installs in seconds.
#
#   requirements-dev.txt      to run the tests
#   requirements-figures.txt  to run scripts/papers_fig.py / scripts/papers_graph.py
#
# `scholarly` used to be here for citation_count.py, which nothing imported;
# the Scholar scrape goes through curl instead, to avoid Python's TLS
# fingerprint being blocked.
#
# Version floors rather than exact pins: this pipeline runs a few times a year,
# and a stale pin that stops resolving is a worse failure than a minor upgrade.
# The floors are not decoration -- CI installs exactly them (the `floor` job), so
# a floor that cannot actually work fails the build instead of failing a stranger.
beautifulsoup4>=4.12
openpyxl>=3.1
# 2.2.2, not 2.0: earlier builds are compiled against the numpy 1.x ABI, so
# pip pairs them with today's numpy 2.x and `import pandas` raises
# "numpy.dtype size changed". Nothing in this repo needs 2.2 features.
pandas>=2.2.2
PyYAML>=6.0
