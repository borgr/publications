% HOW IT WORKS
% ------------
% This file is a template for a publications CV compiled on Overleaf.
% The pipeline (update.py in the GitHub repo) keeps it up to date
% automatically:
%   1. Scrapes Google Scholar → citations.csv + profile_stats.json
%   2. Syncs new papers into papers.csv
%   3. Resolves arXiv entries to published BibTeX in orig.bib
%   4. Builds Wzmn.bib from orig.bib + papers.csv metadata
%   5. Rewrites \nocite{} blocks and the Citations/h-index line in main.tex
%   6. Commits and pushes to this Overleaf project and to GitHub
%
% Run: python update.py   (from the publications/ directory)
%
% HOW OLD ARE THE NUMBERS
% -----------------------
% Step 1 runs from a weekly job on your own machine, not from CI: Google
% Scholar answers a datacenter address with a CAPTCHA rather than with data,
% so a hosted runner cannot fetch it. The counts are therefore as of the date
% in the comment beside them — which is not \today, and drifts once the
% machine is off for a while.
%
% WHAT TO UPDATE MANUALLY
% -----------------------
% 1. Author name and Scholar ID: edit config.py (single source of truth).
%    The pipeline rewrites the BST files and this document's header
%    automatically on each run.
%
% 2. papers.csv: the source of truth for paper metadata
%    (venue, authors, year, bib key, category flags).  Add new papers
%    there; the pipeline will pick them up on the next run.
%
% 3. The \section*{Contributions note} text below explains the ST/PI
%    superscript convention — edit it to match your own conventions.
%
% 4. Chapter structure: each \chapter*{} block ends with \putbib.
%    The \nocite{} lines are auto-regenerated; do not edit them by hand.
%
% FLAGS / OPTIONS
% ---------------
% Show citation counts next to each entry:
%   The BST emits \bibcitecount{N} when a citations={N} field is present.
%   Swap which \bibcitecount line is commented to toggle on/off (default: off).
%
% Bibliography style:
%   planyr-rev  — reverse chronological (default)
%   planyr      — chronological
%   iclr-based  — ICLR style
%   acl-based   — ACL style
% ============================================================
